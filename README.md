NMF Eigenvectors built from SDSS DR14 Quasars
---------------------------------------------

Nonnegative matrix factorization (NMF) based eigenvectors (or basis vectors) built from SDSS DR14 Quasars. They can be used to construct continuum for any SDSS like (e.g. DESI) quasars. 

The full description to build NMF eigenvectors is detailed in [Anand et al. 2021](https://arxiv.org/abs/2103.15842). If you use these eigenvectors in your research, please cite my paper. I would also ask you to cite original NMF paper by [Zhu 2016](https://arxiv.org/abs/1612.06037). 

To get the data just clone the repo:

    `git clone <repo>`

Please read data/eig_README.md for details on file structure.
